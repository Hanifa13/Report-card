Student Report Card Management System
About Project
The Student Report Card Management System is a Java-based console application that calculates a student's total marks, average marks, SGPA, grade, and pass/fail status.
This project demonstrates basic Java programming concepts such as user input, variables, arithmetic operations, conditional statements, and credit-based SGPA calculation.
Features
- Accepts student details:
  - Name
  - Branch
  - Roll Number
  - Semester
- Accepts marks for five subjects:
  - Java
  - Python
  - Advanced DSA
  - DLCO
  - DMGT
- Accepts credit points for each subject.
- Calculates:
  - Total marks
  - Average marks
  - SGPA
- Displays: 
  - Pass/Fail result
  - Grade based on average marks
Technologies Used
- Java
- Scanner Class
- Variables and Data Types
- Conditional Statements
- Arithmetic Operations
Working Process
1. The user enters student information.
2. Marks for each subject are entered.
3. Credit points for each subject are provided.
4. The program calculates total marks and average.
5. SGPA is calculated using subject marks and credits.
6. The final result and grade are displayed.
